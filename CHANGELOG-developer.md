Requires SkyrimNet 0.25.0 or later (built against SkyrimNet beta26 rc4).

- **Punish torture spells**: new `Aid::PunishSpells` replaces `WeakAttackSpells` in `Hud::OnPunish`, `OrgasmEngine::PunishNarrated` and the mini-game player turn. With Injury Engine installed it returns `Aid::TortureSpells` (SPEL 0x816–0x818 in `Injury_Engine.esp`, `minDamage` 0): the ones the player knows for the player; all three for an NPC when `injury_engine.action.require_whip` (new `InjuryEngine::RequireWhip`) is off, else none. `Aid::PunishSpellDisplayName` drops the " (torture)" suffix for narration and player-turn options ("… with Sparks").
- **1.6x animation change at stage 1**: SexLab `SetAnimation` keeps the current stage. `Scene.ApplyRestartStageOnAnimationChange` (`GoToStage(1)` while `Animating`, else `pending_stage_restart` until the next `StageStart`) runs from `CheckAnimationChange`, `NoteSeededRegistry` (Scene Menu) and `StageStart`; `WebUI_SwitchToRegistry` may `GoToStage(1)` before `SetAnimation` when still `Animating`. P+ unchanged. Traced as `RestartStageOnAnimationChange`.
- **`sexlab.enjoyment.engine_disabled`**: SexLab owns enjoyment and orgasms. `Settings::engineOff` (forces `miniGame` false); the tick fires only forced requests, skips gain / strategies / gate / safety net / group join; `NoteExternalOrgasm` skips `JoinGroup`; `AllowOrgasm` only unblocks; `Arouse` / `Calm` return false; `Effect_Mirror` becomes a 1 s pull (`Scene.Mirror_Apply` → `SetEnjoyment(…, "sexlab")`). `Engine_BeginScene` sets `DisableAllOrgasms(false)` and `Engine_SetStage` sends no synthesized hooks. New natives `SexLabNet::IsOrgasmEngineDisabled`, `OrgasmEngine::IsEngineDisabled` (Papyrus `IsEngineDisabled`). `SetEnjoyment` logs on change only. See docs/developers/orgasm-engine.md#engine-disabled.
- **BondagePanel Start fix**: `TM_BondageFinish` iterated `group-devices.json` (83 Arms devices) while the panel lists the DD NG API catalog (233), so a worn device missing from the file was neither unlocked nor narrated and nothing was logged. It now iterates the payload's `current` / `original` group keys and `ChangeDevice` resolves ids via `ArmorFromWantedId` (file lookup only adds rendered / keyword hints), logs the payload and every group change, and notifies on failure. `TM_BondageApply` also locks by id when the device is not in the file. Removed `SetGroupToId`, `UnlockWornInGroup`, `OriginalIdForGroup`, `OriginalIdAt`, `CurrentIdForGroup`.
- **Ask / Order / Punish**: the HUD Punish panel is now subject / verb / object. `OrgasmEngine::AskOrderNarrated` (Papyrus `OrgasmEngine.AskOrder`) narrates "Bob orders Nina to <order>.", runs the target's decision (`StrategyDecision::RequestAnswer`, triggers `asked` / `ordered` / `punished`; `RequestPunished` is gone) and narrates "Nina agrees to|refuses Bob's request to <order>." as its own DirectNarration (DirectNarration when the scene has the player or the player controls an actor of it, else `DirectNarration_Optional` through the new `Effect_NarrateOptional`). Refusals (and reasons other mods add with `AddPunishReason`) are kept per actor as `PunishRecord` (`by`, `target`, `reason`, `strategyKey`, `request`, `type`); the punish verb needs one. `GetPunishReasonPhrases` is replaced by `GetRequestOptions` and `GetPunishReasons`; `onPunishResult` now carries `verb`, `subject`, `object`.
- **Punish line and feeling text**: "Bob punishes Nina by pinching Nina's nipples, because <reason>." plus the text returned by the new Injury Engine `External_TortureText` (`InjuryEngine::PunishText`, silent hit); the narration is the decision's `last_line_text`. The old "gives in / wavers / defies" tail is gone; a punishment for a refused request gets the agree / refuse line. Without `External_TortureText` Injury Engine narrates through `External_Damage` as before.
- **strategies.json is the strategy list**: `passive`, `mutual`, `selfish`, `selfless`, `deny_self`, `deny_all`, `deny`, `tease`, `focused`, `nonsexual`, with the new `order` text. Removed `together`, `greedy`, `forcedorgasm`, `acceptforce`, the forced state (`forcedBy`, `forcedAction`, `ReleaseForced`, `GetForcedBy`, `SetForceMethod`) and the `*_resisted` / `text_method` texts. `Strategy` ids (Papyrus `SetStrategy`, the C++ API) follow the file; old co-save strategies are not restored (SexLab stops scenes on load). **API break** (`OrgasmEngineAPI.h`): the `Strategy` values changed, `IOrgasmEngineV1::IsMentallyBroken` and `EngineEventType::kMentalBreak` are removed.
- **Mental break removed**: `ActorState::broken`, `UpdateBroken`, `IsMentallyBroken` (C++ and Papyrus), the `SkyrimNet_SexLab_MentalBreak` mod event, the HUD `broken` flag and the `sexlab.minigame.mental_break` / `break_drain` settings.
- **Decision prompt**: `minigame_strategy.prompt` / `minigame_player_turn.prompt` ask which strategy the NPC decides to start using, from a single `timeline` (`BuildTimeline`: the actor's recent `PublicGetRecentEvents` as "X said:", "X thought:", narrations and events, narration inside speech on its own line) instead of `recent_dialogue`. The current approach, partner approaches, forced / broken text, scene progress and the punishments block are no longer sent.
- **Strategy texts in `strategies.json`**: the label, phrase, decision option and observed text of every strategy moved from the `kStrategies[]` table in `OrgasmEngine.cpp` to `SKSE/Plugins/SkyrimNet_SexLab/strategies.json` (array of objects matched by `key`; optional `option_resisted`, `text_resisted`, `text_resisted_method`, `observed_resisted`, `text_method` for the forced variants; `{method}` is the force method). Keys and the enum stay in C++. Read by `ReloadConfig`, so a config reload picks up edits. A missing or invalid file keeps the texts in use (first load: each text is its key) and logs a warning.
- **No victim-only strategies**: removed `reject` (Hold back) and `cumquick` (Cum quick). Every remaining strategy is open to every actor regardless of role (Tease / Greedy / ForcedOrgasm need 2+ actors, Greedy / Tease may target anyone); forced actors choose between `acceptforce` and `selfish`. Strategy ids 6+ shifted down by 2 (greedy 6, forcedorgasm 7, acceptforce 8, nonsexual 9) in C++, `OrgasmEngineAPI.h` and `StrategyId()`; co-save record Removed from `SexLab_Force.yaml` and the victim default pulldown; Punish reasons list every strategy.
- **Punishments change strategies**: a punished NPC's strategy is decided before the punishment is narrated, and that one narration says how they took it ("Nina gives in and now …", "… wavers but still …", "… defies Bob and still …"). The decision sees every punishment this scene and treats each reason as a demand; keeping the punished approach is open defiance, and less likely each time. Before, the decision never saw punishments and kept a passive NPC passive however often she was punished. A reason typed as "for being passive" no longer reads "for for being passive".
- **Clean Cum**: a TargetMenu *Clean Cum* option, shown only on actors with cum, opens "*who* cleans cum from *actor*'s *body part*" with a style (roughly, normally, gently, silently). The body-part list holds only the places that still have cum, plus *all*. Cleaning clears that part from the character bio and the SexLab overlay. NPCs can do it too with the new `sexlab_clean_cum` action, offered while anyone nearby has cum.
- **Enjoyment wording**: `0050_sexlab_activity.prompt` now describes `enjoyment` as how close an actor is to orgasm ("building steadily toward orgasm", "nowhere near orgasm yet") and not as arousal, which scene start sets to at least 35 ("moderately_aroused") for non-victims.
- **Quieter Arouse / Calm**: arousing or calming someone no longer makes anyone speak or adds a line to the orgasm narration; NPCs just briefly know it happened.
- **Simpler sex / affection picks**: animations with any sex act are now tagged *sexual* (the list is in `sex_tags.json`). The TargetMenu's *sex* is now *sexual*, with no sub-choices. *Affection* and *platonic* just leave out sexual animations, and platonic leaves out kissing too. While Scene Creator is open, clicking *sexual*, *affection* or *platonic* sets the creator's tag filters instead of opening their panel. *Custom* opens Scene Creator already filtered to *sexual*.
- **Scene Creator only lists free actors**: actors already in a scene, or just picked for one that is starting, are no longer offered. In the Control Panel they show as *Name (SexLab)* or *Name (locked)*. Nearby actors you can't pick are greyed out with the reason, e.g. *Name (Ostim)*, *Name (Dead)*, *Name (Combat)*.
  - **Scene Creator adding actors**: clicking a nearby actor adds them again. Before, an actor could fail to join (for example as a third actor) and then stay unclickable until the menu was reopened.
- **Take control (Num \*)**: a new key, shown above Num - on the HUD.
  - **Auto play**: in your own scene, press it to let the AI play you (the cell then reads *control*). It picks how you behave, presses the HUD keys for you (stage, speed, pause, deny, end, aid, punish, including what to pick in the Aid and Punish panels), and after someone speaks it may have you answer. You can still press any key yourself. Press again to take back control. Needs the Multi-Orgasm Mini-game and a SkyrimNet decisions provider.
  - **Control an NPC**: aim at someone in a scene you're not in and press it. The HUD shows that scene "as *name*", and your keys act as that NPC (their stamina and magicka pay). Press again to let go.
- **NPC strategies by the decision model**: in the Multi-Orgasm Mini-game, SkyrimNet's decision model (for example Jev) now picks how each NPC plays: for everyone when a scene starts, and again for an NPC after each line they speak. It weighs the NPC's personality, role, what was just said, how the scene came about, and their Skyrim relationship with each partner. The old strategy actions are gone. Others in the scene may notice a change ("Lydia appears to be focused on her own enjoyment."); there is no popup notification. Needs a **decisions** provider in SkyrimNet; without one, NPCs keep the default strategies. Turn off with **Decision model picks NPC strategies** (Mini-game settings). The model only changes a strategy when it is fairly sure; set how sure with **Decision minimum confidence** (Mini-game settings, default 0.6).
- **Mini-game pacing**: orgasms no longer come in the first half of a scene. Each scene's pace is set from its SexLab stage timers, so when everyone plays Mutual, both partners are close (87%) just before the last stage. Pausing, going back a stage or long dialogue add more, so more orgasms are possible. In your own scenes you have to play your part. New settings **Mini-game Mutual target** and **Mini-game passive share** (Enjoyment).
  - **Orgasm rolls fixed**: partners only climax together when close to the edge (enjoyment plus a small random bonus reaches 100). Before, someone at 30% enjoyment had a 30% chance. **Orgasm roll random bonus** is now under Enjoyment settings.
  - **Paused time**: arousal, orgasm cooldowns and edging no longer advance while the game is paused or a menu is open.

Uses **Orgasm check before the last stage** (Scene ending settings).

### 0.35.1 

- **Position hotkeys**: new **PgUp / PgDn** scene keys swap the actors' roles forward / back (rebindable in the Plugin settings). The hotkey overlay grows a column to show them.
- **Narrate position changes**: new option (on by default) narrates the new stage description with the actors in their new roles.
- **Description Editor**: **continue scene** now closes the WebUI after sending its narration.
- **TargetMenu cleanup**: the Stop / Stage / Position / Animation entries are gone from the in-scene Scene menu; the Description Editor and the new position hotkeys cover them. If you install by hand (not a mod manager), delete the four old files `0100_stop`, `0200_stage`, `0300_position` and `0400_animation` from the TargetMenu Scene folder.
- **Deny / allow orgasm**: the Transform option is gone. Denying and allowing are plain events again: "Bob forbids Nina from orgasming without permission." / "Bob permits Nina to orgasm."
- **Hug fix**: a single hug no longer leaves you unable to attack with your weapon (e.g. a whip) afterward. Both people now put their weapons away before hugging.
- **Newer Skyrim support**: the SKSE plugin is rebuilt for Skyrim 1.7.x / 1.7.99 and works with SkyrimNet beta26 rc4.
- **Camera**: locking the free camera (Num 3) mid-scene returns the normal third-person camera with mouse look enabled, and when a scene ends the camera goes back to the mode it was in when the scene began (first person stays first person).
- **Mouse mini-game**: right mouse now arouses and left mouse calms during mini-game scenes by default. Turn **Allow right mouse to arouse and left mouse to calm** off in the Mini-game settings to go back to keys only.
