# Injury Engine rename handoff (SkyrimNet_SexLab)

SkyrimNet_Whipped is being renamed **Injury_Engine** before its first release. This repo uses it as a soft dependency: Punish wounds, Aid heals, and the HUD's sexual-parts gate. It must follow the rename. The full spec covering all three repos is `../SkyrimNet_Whipped/injury-engine-handoff.md`. This file lists only what changes here.

- New names on the Injury Engine side: plugin `Injury_Engine.esp`, main script `Injury_Engine_Main`, dashboard config `Injury_Engine` (C++ name without `Plugin_`), setting `injury_engine.body.include_sexual_parts`.
- The mod has never shipped, so keep no fallback to the old names.
- Deploy this repo together with the renamed Injury Engine. An old SexLab DLL looks up `SkyrimNet_Whipped.esp` and will treat Injury Engine as missing.
- This repo has uncommitted work. Keep it; do not revert or stash it.
- Do not commit unless asked. Do not edit this file during a search-replace.

## Substitution rules

Apply in this order, case-sensitive. Do **not** blind-replace the substring `whip`. Do not touch anything under `extern/`.

| From | To |
|------|-----|
| `SkyrimNet_Whipped` | `Injury_Engine` |
| `skyrimnet_whipped` | `injury_engine` |
| `SkyrimNet Whipped` | `Injury Engine` |
| `whip.body.include_sexual_parts` | `injury_engine.body.include_sexual_parts` |
| code identifier `Whipped` (meaning that mod) | `InjuryEngine` |
| lowercase `whipped` key / CSS / local (meaning that mod) | `injuryengine` (JSON / CSS) or `injuryEngine` (C++ / JS locals) |
| JS state object `WHIPPED` | `INJURYENGINE` |
| prose "Whipped" (meaning that mod) | "Injury Engine" |

## Build

The DLL build globs `src/*.cpp`, so the renamed file needs a fresh configure. There is no `make dll` target here.

```text
cd SKSE_Source
cmake --preset release            # fresh configure
cmake --build --preset build-release
copy build\release\Release\SkyrimNet_SexLab.dll ..\SKSE\Plugins\
cd ..
pyro skyrimse.ppj                 # required: native name changed
```
